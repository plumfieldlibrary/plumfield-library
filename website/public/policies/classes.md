# Library Classes

## Policy overview

Plumfield Library classes are available to members through the Patron Dashboard. This policy explains registration, payments, and cancellation rules.

## Key points

- Full Membership gives access to class registration in the Patron Dashboard.
- Invoices can be viewed and paid through the dashboard.
- Classes are non-refundable; if a class is canceled by the teacher, Plumfield will work toward a fair solution.

Read the full human page at [/library-policies/classes](/library-policies/classes).
