# Holds

## Policy overview

Holds can only be placed from the Plumfield Library Libib catalog. This policy explains why holds are not available through the patron dashboard and how to place them.

## Key points

- Holds must be placed from the Libib website.
- Requests must be submitted at least 48 hours before pickup.
- For holds to be picked up at other branches, refer to the Interlibrary Loan policy.

Read the full human page at [/library-policies/holds](/library-policies/holds).
