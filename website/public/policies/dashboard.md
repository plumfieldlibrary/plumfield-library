# Patron Dashboard

## Policy overview

The Patron Dashboard is the central hub for managing membership, classes, invoices, branch information, and interlibrary loan requests.

## Key points

- Use the dashboard to view invoices, class registrations, and branch details.
- Sign in with your email to receive a one-time login link.
- The dashboard also provides access to interlibrary loan request forms and class sign-ups.
